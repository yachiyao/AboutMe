# 鄧棋耀 (Cassell Teng) - 個人作品集 Portfolio

> 具備 10 年以上動漫與遊戲跨界歷練，全程參與 PSVita《出包王女-真實公主》對日開發與規格推進；精通日文商務溝通 (JLPT N1)、背景美術繪圖與 Unity 專案管理。目前深造 AI 專案管理與前端技術，專精運用大型語言模型輔助專案落地。

---

## 📱 專案亮點 (Highlights)

- **Mobile-First 響應式架構**：首頁採用手機優先體驗設計，整合底部導航欄、分類標籤、深淺色模式切換與快捷數據看板。
- **純前端即開即用 (Zero-Config)**：所有作品均為純原生前端設計（HTML5 / Tailwind CSS / Vanilla JS），無須額外建置後端即可直接運行。
- **高隱私與安全演算法**：包含多款在地端瀏覽器運算之個資脫敏（PII 去識別化）工具，資料 100% 不上傳伺服器。

## 🛠️ 技術棧與 API 整合 (Tech Stack & APIs)

| 分類 | 技術 / API | 應用說明 |
| :--- | :--- | :--- |
| **前端框架與樣式** | Tailwind CSS, FontAwesome, Lucide Icons | 現代化響應式 UI、卡片式佈局與深淺色主題 |
| **圖表與可視化** | Chart.js, 原生 SVG 向量引擎 | 血壓趨勢折線圖、財務現金流瀑布圖與結構對比長條圖 |
| **第三方開放 API** | Open-Meteo API, Tarot API, Free Horoscope API | 即時氣象觀測、78 張塔羅牌庫抽取、每週星座運勢資料串接 |
| **自動化與雲端** | Google Apps Script, Google Sheets CSV, LINE URL Scheme | 飲料線上訂單轉發、試算表即時名冊同步、LINE 訊息轉送 |
| **資料處理與隱私** | SheetJS (xlsx), HTML5 File API, RegExp Engine | 多工作表 Excel/CSV 本地解析匯出、企業機密欄位掩碼假名化 |
